# Quick Start

This guide provisions a personal Afilmory Edge gallery on Cloudflare. You need Git, pnpm, Node.js 20+, and the `cf` CLI.

## Step 1: Configure the site

```bash
pnpm install
cp config.example.json config.json
cp apps/edge/.dev.vars.example apps/edge/.dev.vars
```

Edit `config.json` with your gallery name, author, accent color, and map settings. Site settings saved later from the dashboard are stored in D1 and take precedence.

## Step 2: Provision Cloudflare resources

```bash
cf d1 create --name afilmory-db
```

Create a private OSS bucket in the Aliyun console. The KV namespace is provisioned automatically by `bindings.kv({})` on first deploy. Update the names in `apps/edge/cloudflare.config.ts` if you chose different ones, then apply the D1 schema (remote by default; find the ID with `cf d1 list`):

```bash
cf d1 migrations apply <database-id> --dir be/packages/db/migrations
```

Set the Worker secrets (`CONFIG_ENCRYPTION_KEY`, the `S3_*` OSS credentials, and so on). See [Deployment](/deployment) for the full list.

## Step 3: Build and deploy

```bash
pnpm build
pnpm deploy:edge
```

`pnpm build` builds the gallery SPA and dashboard, syncs them into `apps/edge/public`, and bundles the Worker.

## Step 4: Create the owner account

```bash
pnpm bootstrap:admin --email you@example.com \
  --account-id <account-id> --database-id <database-id> --api-token <api-token>
```

Registration is disabled. Sign in at `/platform/` with the account you just created.

## Step 5: Upload photos

Open the dashboard and drop photos into the upload area. The dashboard uploads originals directly to OSS with a presigned URL, renders a 600px thumbnail and ThumbHash in the browser, then asks the Worker to extract metadata and publish the manifest. HEIC/HEIF files and Live Photo pairs are supported directly.
