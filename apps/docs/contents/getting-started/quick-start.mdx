# Quick Start

This guide provisions a personal Afilmory gallery on Cloudflare. You need Git, pnpm, Node.js 20+, and the `cf` CLI.

## Step 1: Configure the site

```bash
pnpm install
cp config.example.json config.json
cp builder.config.default.ts builder.config.ts
cp apps/edge/.dev.vars.example apps/edge/.dev.vars
```

Edit `config.json` with your gallery name, author, accent color, and map settings.

## Step 2: Choose storage

The Worker's runtime uploads use R2 through the `PHOTOS` binding. If you also want to run the bulk builder, configure its storage provider in `builder.config.ts`:

- **S3** — recommended for large collections
- **B2** — cost-effective object storage
- **GitHub** — repository-backed storage
- **Local** — development and testing
- **Eagle** — import an Eagle library

See [Storage Providers](/storage/providers) for credentials and options.

## Step 3: Provision Cloudflare resources

```bash
cf d1 create afilmory-db
cf r2 bucket create afilmory-photos
cf kv namespace create AFILMORY_CACHE
```

Update the IDs in `apps/edge/cloudflare.config.ts` if you chose different names, then apply the D1 schema:

```bash
cf d1 migrations apply afilmory-db --remote
```

Set the Worker secrets (`CONFIG_ENCRYPTION_KEY`, R2 credentials, and so on). See [Deployment](/deployment) for the full list.

## Step 4: Build and deploy

```bash
pnpm build
pnpm deploy:edge
```

`pnpm build` builds the gallery SPA and dashboard, syncs them into `apps/edge/public`, and bundles the Worker.

## Step 5: Create the owner account

```bash
pnpm bootstrap:admin --email you@example.com \
  --account-id <account-id> --database-id <database-id> --api-token <api-token>
```

Registration is disabled. Sign in at `/platform/` with the account you just created.

## Optional: bulk photo import

To process a large existing collection with the builder:

```bash
pnpm build:manifest               # incremental
pnpm build:manifest -- --force    # full rebuild
```

This writes thumbnails and `apps/web/src/data/photos-manifest.json`. Runtime uploads from the dashboard do not require the builder.
