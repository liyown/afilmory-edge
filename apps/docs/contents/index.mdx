# Overview

Afilmory is a personal, single-tenant photo gallery. One owner account manages one gallery on one domain, deployed as a single Cloudflare Worker with D1, R2, and KV bindings.

## What is Afilmory?

Afilmory turns a photo collection into a fast, modern gallery. Photos live in R2 (or another storage provider via the builder), metadata lives in D1, and the Worker serves the gallery SPA, the admin dashboard, and the API from the same origin.

## Key Features

- **WebGPU viewer** — GPU-accelerated zoom, pan, and navigation with a WebGL fallback
- **Masonry grid** — Responsive layout with ThumbHash placeholders
- **Rich metadata** — EXIF, Live Photos, HDR gain maps, Fujifilm recipes
- **Map view** — Geotagged photos on an interactive map
- **Live uploads** — Dashboard uploads land in R2 and update the D1-backed manifest immediately
- **SEO and social** — Dynamic OG images and per-photo metadata rendered by the Worker
- **Single-tenant auth** — Better Auth with registration closed; the owner account is bootstrapped from the CLI

## Prerequisites

- A Cloudflare account with Workers, D1, R2, and KV enabled
- Node.js 20+
- pnpm
- The `cf` CLI

## Quick Start

1. **Configure** — copy `config.example.json` and `builder.config.default.ts`, then fill in `.dev.vars`
2. **Provision** — create D1, R2, and KV resources and apply the D1 migration
3. **Deploy** — run `pnpm build` and `pnpm deploy:edge`
4. **Bootstrap** — create the owner account with `pnpm bootstrap:admin`

See the [Quick Start Guide](/getting-started/quick-start) and [Deployment](/deployment) for the full walkthrough.
